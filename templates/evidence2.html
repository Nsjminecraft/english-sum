The Project
The Project

The project I chose is an interactive, choice-based text game developed using Python, which is hosted on GitHub (french-game). Built to make practicing French vocabulary and grammar more engaging, the creation of this project required a heavy application of two key transferable skills: Critical Thinking & Problem Solving and Self-Directed Learning.

Skill
Skill

Building a branching text-based game required intense logical planning. It involved designing a complex network of conditional statements to handle player choices, track game states, and ensure that a user's decisions dynamically impacted their score and the storyline. When a player makes a specific choice, the game must instantly validate the French input and route them to the correct narrative path. Debugging these intersecting choice trees required deep analytical thinking to prevent logic loops, resolve syntax errors, and ensure a seamless user experience.

While a basic coding foundation was already there, taking on an entire interactive game required learning advanced software concepts completely independently. It involved researching how to manage complex logic structures in Python and reading documentation to optimize how the program processes text input. Managing this project outside of standard classroom templates meant setting development milestones, troubleshooting errors without external help, and maintaining the discipline needed to turn an abstract idea into a fully functional, open-source educational tool.

Explain how you use one of these skills in another course or in your life outside of school.

The skill of Critical Thinking & Problem Solving is something that transfers directly into my life outside of school, especially when managing my home server and homelab environment. In this setup, I frequently deal with complex systems involving Docker container management and storage array configurations like RAID.

When a service goes down or a data array encounters an error, there is no step-by-step school rubric to follow. I have to apply the exact same analytical logic used in my programming projects to diagnose the root cause of the issue. This involves checking system logs, isolating variables to see which container or network configuration is causing the conflict, and systematically testing solutions without risking data loss. Being able to break a massive, intimidating technical failure down into smaller, manageable troubleshooting steps is a direct application of problem-solving that keeps my local infrastructure running smoothly.

Identify one transferable skill you would still like to improve upon. How will you do this?

The transferable skill I would still like to improve upon is Collaboration. While I am highly confident when working independently on technical tasks and software development, I recognize that the most impactful projects require a team effort. Working with others introduces different perspectives, programming styles, and communication needs that are vital to navigate successfully. To do this, I plan to actively seek out group environments where I have to share development responsibilities rather than building everything solo. For example, I will participate in upcoming hackathons with a dedicated team, dividing up tasks such as front-end design, back-end logic, and project presentations. Additionally, I intend to contribute to open-source repositories on GitHub, which will force me to practice reading other people's code, submitting pull requests, and engaging in constructive code reviews and discussions with other developers.
